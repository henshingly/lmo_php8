# Club schedule

The Club schedule add-on creates an overall schedule of your club from all LMO leagues, with freely selectable leagues and teams. The output files can be included in your homepage via a link.

![Club schedule view](./assets/media/vereinsplan01.png)

**Features:**

- Extensive configuration options in the admin area
- Output either as a dynamic view (slider function per month) or a static view
- Creation of overall, home and away schedules
- Compact results list relating to the current match day
- PDF export of the club schedules
- Support for many LMO output variables in the supplied templates

- A working LMO 4
