# Team comparison

3. [Download](#3-download)
4. [Version history](#4-version-history)

The team comparison is an add-on for LMO 4. It compares the matches of the current season with any leagues you define and outputs them, if available. The appearance can be freely adapted via [templates](#2-templates). You can also use the team comparison without archive leagues, e.g. as an orientation aid in the betting game. This way you see at a glance the table position, first and second leg, past meetings and more.

---

## 1. System requirements

- A working LMO 4
- Installed Classlib add-on with PDF class for LMO 4 by Tim Schumacher (available in the add-on archive)

---

## 2. Templates

As with the LMO, you can freely adapt the structure and design of the team comparison. After installation you find examples in the subdirectory `stats` of the template folder `template`. You can create any number of templates (extension `.tpl.php`).

> Detailed installation instructions are included with every version.
