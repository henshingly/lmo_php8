# Add-ons

Add-ons extend the LMO with additional functions. Some are part of the package, others are available as a separate download.

---

## Built-in add-ons

| Add-on | Description |
|---|---|
| [Betting game](#addon-betting-game) | Comprehensive and flexible betting game (Tippspiel), including entering tips retroactively as admin |
| [Player statistics](#addon-player-stats) | Appearances, goals, cards: publish player statistics |
| [Mini tables](#addon-mini-tables) | Compact table for your start page or other pages |
| [News ticker](#addon-newsticker) | Results ticker as a scrolling bar (needs jQuery, included in the package) |
| [Mininext](#addon-mininext) | Next match of a team in a compact block, plus earlier meetings |
| [Viewer](#addon-viewer) | Results and fixtures of any leagues, across leagues and extremely flexibly configurable; you can include it on any page of your homepage |
| **Classlib** | Library with numerous classes and methods for object-oriented development in the LMO, which makes access to the information in a league file much easier. As a central element it includes further libraries (e.g. a PDF library). The modularisation concept allows HTML code to be moved into globally available, reusable functions. Even if you notice no change on the surface, most add-ons listed here use the Classlib. |

---

## Further add-ons

These add-ons are not part of the package and are downloaded separately.

> **Note:** The list is not complete. More add-ons can be found in the [support forum archive](https://www.liga-manager-online.org/forum/viewforum.php?f=11) at liga-manager-online.org.
>
> The following add-ons date from the LMO 4.0 era. They need the **PDF class**, which is not included in the package, and have not yet been checked with PHP 8.2.

| Add-on | Description |
|---|---|
| [Club schedule](#addon-club-schedule) | Schedule of a club with all its teams as PDF |
| [Team schedule](#addon-team-schedule) | Schedules of the teams as PDF |
| [Team comparison](#addon-team-comparison) | Previous meetings of two teams at a glance |
| [PDF schedule](#addon-pdf-schedule) | Schedule of a league as PDF |
| [Top tipper](#addon-top-tipper) | Extension for the betting game: current standings as a mini table |
| [JSON API and league view](#addon-api) | League data as a JSON interface and a ready-made league view with designs for other sites |
| [ICS calendar](#addon-ics) | A team's fixtures as an ICS file or calendar subscription (Google, Apple, Outlook, Thunderbird); link in the table |
