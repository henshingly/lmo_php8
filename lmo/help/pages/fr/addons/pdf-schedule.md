# Calendrier PDF

1. [Configuration requise](#1-configuration-requise)
2. [Téléchargement](#2-telechargement)

![Vue du calendrier](./assets/media/spielplan.png)

Avec cet addon, tu peux créer le calendrier de ta ligue sous forme de document PDF. Après l'installation, un autre lien apparaît sous le lien « Imprimer le calendrier de la ligue », qui crée et affiche le PDF directement dans le navigateur.

---

## 1. Configuration requise

- À partir de LMO 4.0+ : l'addon exige impérativement l'addon Classlib avec classe PDF pour LMO 4 de Tim Schumacher (disponible dans l'archive des addons). Aucune bibliothèque PHP supplémentaire n'est nécessaire.
