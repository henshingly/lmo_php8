# Addons

Les addons étendent le LMO avec des fonctions supplémentaires. Certains font partie du paquet, d'autres sont disponibles en téléchargement séparé.

---

## Addons intégrés

| Addon | Description |
|---|---|
| [Jeu de pronostics](#addon-betting-game) | Jeu de pronostics (Tippspiel) complet et flexible, avec saisie rétroactive des pronostics par l'admin |
| [Statistiques des joueurs](#addon-player-stats) | Apparitions, buts, cartons : publie des statistiques de joueurs |
| [Mini-classements](#addon-mini-tables) | Classement compact pour ta page d'accueil ou d'autres pages |
| [Ticker d'actualités](#addon-newsticker) | Ticker de résultats sous forme de bandeau défilant (nécessite jQuery, inclus dans le paquet) |
| [Mininext](#addon-mininext) | Prochain match d'une équipe dans un bloc compact, avec les confrontations précédentes |
| [Viewer](#addon-viewer) | Résultats et rencontres de n'importe quelles ligues, toutes ligues confondues et configurable de façon extrêmement flexible ; tu peux l'intégrer dans n'importe quelle page de ton site |
| **Classlib** | Bibliothèque avec de nombreuses classes et méthodes pour le développement orienté objet dans le LMO, qui facilite grandement l'accès aux informations d'un fichier de ligue. Élément central, elle inclut d'autres bibliothèques (p. ex. une bibliothèque PDF). Le concept de modularisation permet de déplacer du code HTML dans des fonctions réutilisables disponibles globalement. Même si tu ne remarques aucun changement en surface, la plupart des addons listés ici utilisent la Classlib. |

---

## Autres addons

Ces addons ne font pas partie du paquet et se téléchargent séparément.

> **Remarque :** La liste n'est pas exhaustive. D'autres addons se trouvent dans les [archives du forum de support](https://www.liga-manager-online.org/forum/viewforum.php?f=11) sur liga-manager-online.org.
>
> Les addons suivants datent de l'époque du LMO 4.0. Ils nécessitent la **classe PDF**, qui n'est pas incluse dans le paquet, et n'ont pas encore été testés avec PHP 8.2.

| Addon | Description |
|---|---|
| [Calendrier du club](#addon-club-schedule) | Calendrier d'un club avec toutes ses équipes en PDF |
| [Calendrier de l'équipe](#addon-team-schedule) | Calendriers des équipes en PDF |
| [Comparaison d'équipes](#addon-team-comparison) | Confrontations précédentes de deux équipes en un coup d'œil |
| [Calendrier PDF](#addon-pdf-schedule) | Calendrier d'une ligue en PDF |
| [Top Tipper](#addon-top-tipper) | Extension du jeu de pronostics : classement actuel sous forme de mini-classement |
| [API JSON et vue de ligue](#addon-api) | Données des ligues sous forme d'interface JSON et de vue de ligue prête à l'emploi avec designs pour d'autres sites |
| [Calendrier ICS](#addon-ics) | Matchs d'une équipe sous forme de fichier ICS ou d'abonnement de calendrier (Google, Apple, Outlook, Thunderbird) ; lien dans le classement |
